Put your Firebase service account JSON file in this folder.

1. Open: https://console.firebase.google.com/project/wawatair-b212f/settings/serviceaccounts/adminsdk
2. Click "Generate new private key"
3. Save the downloaded file here (any name, e.g. service_account.json)
4. Run: cd /Users/dart/StudioProjects/wawat && fvm dart run bin/send_fcm.dart "YOUR_FCM_TOKEN"

Do not commit the JSON file to git (it is in .gitignore).
