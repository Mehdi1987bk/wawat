# CMS key to add — `search.type_placeholder`

Новый ключ для CMS (`GET /content?lang=`). Приложение **уже** его использует
(с AZ-фолбэком), поэтому как только бэкенд добавит ключ с переводами — текст
подтянется автоматически, **без обновления приложения**.

- **Ключ:** `search.type_placeholder`
- **Группа:** `search`
- **Где:** главная → фильтр «тип объявления» (кнопка над «Найти»). Показывается,
  когда тип ещё не выбран — вместо «Все». По тапу открывается выбор
  (Все / Поездка / Отправление).
- **Тип:** короткая подпись-плейсхолдер (кнопка), 1 строка, без переменных.

## Значения по языкам

| lang | value |
|------|-------|
| `az` | Kimi axtarırsan? |
| `ru` | Кого вы ищете? |
| `en` | Who are you looking for? |
| `tr` | Kimi arıyorsun? |
| `ua` (uk) | Кого ви шукаєте? |
| `es` | ¿A quién buscas? |

## JSON для импорта

```json
{
  "key": "search.type_placeholder",
  "group": "search",
  "translations": {
    "az": "Kimi axtarırsan?",
    "ru": "Кого вы ищете?",
    "en": "Who are you looking for?",
    "tr": "Kimi arıyorsun?",
    "ua": "Кого ви шукаєте?",
    "es": "¿A quién buscas?"
  }
}
```

> Примечание: `ua` — это псевдоним для `uk` (украинский), клиент нормализует
> `uk → ua`. Отдавайте под тем кодом, под которым у вас хранятся остальные ключи.
