# Android: пуш при закрытом приложении без звука — бэкенд менять НЕ нужно

> Предыдущая версия этого документа (про data-only и `priority: high`) была
> ошибочной — не применять. Бэкенд уже шлёт `notification + data` с
> `android.priority = high`, это правильно.

## Что было на самом деле
Причина в сборке приложения, не в бэкенде: из release-сборки Android вырезался
файл звука `res/raw/airplane.mp3`, на который ссылается канал уведомлений
`wawat_airplane_v5`. Уведомление показывалось, но играть было нечего.
Исправлено в приложении файлом `android/app/src/main/res/raw/keep.xml`.

На Android 8+ звук уведомления задаёт только канал на устройстве — поля FCM
(`sound`, `default_sound`) на него не влияют. Добавлять их не надо.

## Необязательное усиление (по желанию)
Сейчас бэкенд по умолчанию закрепляет канал `wawat_airplane_v3`
(`config/services.php`, переменная `FCM_ANDROID_CHANNEL_ID`). Приложение этот
канал удаляет, и пуш попадает в правильный `wawat_airplane_v5` только через
запасную ветку Firebase SDK (канал из манифеста). Чтобы от неё не зависеть:

```
FCM_ANDROID_CHANNEL_ID=wawat_airplane_v5
```

в боевом `.env`, затем `php artisan optimize` и `php artisan horizon:terminate`.
Это не срочно и на звук в текущей ситуации не влияет.
