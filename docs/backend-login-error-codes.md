# Login: машинные коды ошибок в конверте ответа

## Зачем
Приложение раньше определяло состояние аккаунта по **тексту** сообщения
(`məhdud`, `suspended`, `cəhd`). У пользователя с ru/en-локалью сервер
присылает сообщение на его языке — азербайджанские подстроки не совпадают,
и блокировка/предупреждение не распознаются.

Теперь приложение решает по **машинному коду** и **HTTP-статусу**, а текст
оставлен лишь как запасной вариант для AZ. Чтобы это заработало для всех
языков, бэкенд при ошибке логина должен класть в тело ответа поле `code`.

## Контракт

Эндпоинт логина при ошибке возвращает JSON:

```json
{
  "message": "Локализованный текст для пользователя",
  "code": "machine_code",
  "errors": { "email": ["..."] }   // опционально, как сейчас
}
```

`message` — как и сейчас, на языке пользователя (можно оставить без изменений).
`code` — **не локализуется**, одно из значений ниже.

### 1. Аккаунт ограничен/заблокирован
Приложение показывает кнопку «Связаться с поддержкой» и красный алерт.

- HTTP-статус: **403**
- `code` — любое из: `account_suspended`, `account_limited`,
  `account_blocked`, `account_restricted`, `account_disabled`,
  `suspended`, `banned`

Достаточно 403 **или** одного из этих кодов (приложение проверяет оба).

### 2. Неверные данные / остались попытки
Приложение показывает жёлтый (предупреждающий) алерт, без кнопки поддержки.

- HTTP-статус: **401** или **422**
- `code` — любое из: `invalid_credentials`, `credentials_invalid`,
  `attempts_remaining`, `too_many_attempts`

### 3. Прочие ошибки
Любой другой ответ — обычный красный алерт. Отдельный код не нужен.

## Минимум, который надо сделать
Достаточно отдавать корректный **HTTP-статус** (403 для блокировки, 401/422
для неверного входа). Поле `code` желательно, но если статусы правильные —
приложение уже всё распознает. Если какой-то кейс не ложится в эти статусы —
напишите, добавим код в список на стороне приложения.

## Примечание
Поле `lang` в `GET /content?lang=` уже поддерживается — отдельных действий не
требует. Новые ключи переводов для CMS — в `docs/i18n-new-keys.json`.
